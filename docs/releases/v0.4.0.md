# Chorono v0.4.0 — Spline modeling and editor precision

Released 17 November 2026. [Türkçe](../tr/releases/v0.4.0.md) · [Validation and limits](v0.4.0-validation.md) · [Changelog](../../CHANGELOG.md)

## Spline modeling

- **Offset** creates a separate editable parallel contour. Closed contours use outward/inward; open contours use left/right.
- **Outline** creates an equal-distance band. Closed bands use even-odd fill; open bands join both sides with caps.
- **Chamfer** trims selected corners and joins them with straight edges.
- **Fillet** rounds selected corners with tangent cubic segments and a radius. Two straight edges use the requested circular radius.
- The Spline Modeling dock panel offers contour and corner selection, distance/direction controls, Preview, Apply and Cancel. Preview stays outside the scene and Undo history. Apply is one Undo step.
- Offset/Outline add a sibling spline layer without changing the source. Chamfer/Fillet replace the chosen contour and reject animation tracks that address its geometry. Revision and document checks reject stale previews.

Curves are sampled to a 0.25 layer-local pixel tolerance, subject to a subdivision limit. Curved-edge fillets are tangent G1 cubic approximations. Zero-length, collapsed, self-intersecting and overlapping results are rejected. The preview is in the modeling panel.

## Scripting and MCP

`layer.spline.offsetContour(contourId, distance, direction)` and `outlineContour(...)` return the new layer ID. `chamferCorners(contourId, pointIds, distance)` and `filletCorners(contourId, pointIds, radius)` edit the source in one native command. These calls use the same geometry as the panel and are available through the isolated MCP scripting bridge. See the [modeling API guide](../en/spline-modeling.md).

The editor also adds **Send to Agent** on selected layers. It copies a short-lived MCP handoff prompt; the agent reads the current scene and focus through `get_handoff_context`. Copying does not start a conversation or grant edit authorization. Source mutations still require a fresh `get_scene` read token and revision.

## Editor workflow

- Snap/Grid controls share one menu, with separate Move, Rotate and Scale settings, parent alignment, a visible grid preference and zoom-adjusted screen hit radius. A follow-up restores 2D move/resize adapters and rotate feedback.
- Shortcuts opens in a separate window. Motion Keys has a dedicated dock panel, while the existing motion-key data and transport remain in the editor.
- Project/export access and interactive preview visibility were refined alongside these controls.

## Validation and scope

The [validation report](v0.4.0-validation.md) records unit, CLI, MCP and production build results, browser Offset preview/Apply/Undo, and known limits. Existing editable spline serialization and render/export paths are reused. Portable save/load and cross-format output for the new modeling results did not receive separate visual acceptance in this release.

The earlier reported Point/Edge/Object modes, complete Boolean workflow, topology tool suite, Auto Close and drawing-to-connect behavior are **not claimed by this release**. Some basic contour/Continue behavior predates it; see the [comparison report](../tr/releases/2026-11-17-spline-script-release-hazirligi.md) for the commit-level distinction.

## Install this version

Requires Node.js 20+, npm, Git and a modern browser:

```sh
git clone --branch v0.4.0 --depth 1 https://github.com/codie1982/chorono-editor.git
cd chorono-editor
npm ci
npm run cli:build
npm run chorono -- setup
npm run chorono -- start --background --open
```

Connect the browser through **MCP → Connect this editor**, reload the agent's MCP connection, then run `npm run chorono -- doctor`. The GitHub release includes a checked CLI tarball; the editor root remains private. This GitHub release does not publish either package to the npm registry.
