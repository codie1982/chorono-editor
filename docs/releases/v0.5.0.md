# Chorono v0.5.0 — Mesh2D, physics baking and fracture

Chorono v0.5.0 adds editable 2D meshes, reviewable physics bakes and deterministic fracture. You can preview results in the editor, keep working on the same portable project, and render a still or an image sequence.

## Mesh2D

- Create a structured grid or generate a mesh from a closed shape or spline. Inspect its topology in the viewport.
- Place and crop textures, pin vertices, and play baked deformation clips. Portable projects preserve the source, mesh and clip data.

## Physics and fracture

- Preview and review track and rigid-body bakes in Jobs & Bake. Applying a bake creates one Undo step. Ownership checks protect edited tracks when replacing or clearing baked output.
- Break supported sources into deterministic Voronoi fragments. Complex regions support concave outlines and holes, and textured Mesh2D fragments preserve the source UVs.
- Author breakable bonds and bake secondary fracture events. Inspect event timing, fragment lineage and collider geometry in the editor or through MCP.

## Render

**Export → Render…** produces a PNG or PNG sequence ZIP with the built-in renderer. With the separate local Chorono Render service running, send a frame or sequence to 2D Video Studio for finishing. Video export through the bridge uses PNG frames and does not include an audio track. [Render workflow](../tr/chorono-render-2d-integration.md)

## Install

After publication, clone the tagged release and start the editor with Node.js 20 or newer.

```sh
git clone --branch v0.5.0 --depth 1 https://github.com/codie1982/chorono-editor.git
cd chorono-editor
npm ci
npm run cli:build
npm run chorono -- setup
npm run chorono -- start --background --open
```

Connect the browser through **MCP → Connect this editor** to work with an agent. The GitHub release bundles the CLI archive for local installation.
