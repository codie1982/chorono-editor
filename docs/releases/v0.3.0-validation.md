# v0.3.0 validation and measurement scope

This report separates fresh release integration checks from the earlier feature
acceptance. Raw recordings, private projects, local working directories and
telemetry are not included in the source release.

## Release integration — 12 November 2026

An isolated worktree integrated the completed pre-3D branch with current `main`
(`4e0e8ff`, including MCP metadata PR #8). The original editor and its working
files were preserved. Seventy selected source/document files were snapshotted;
local `output/`, `work/` and screen recordings were excluded.

Six merge conflicts were reviewed. The integration retains newer typed keyframes,
one-use source-read/revision guards, focused discovery and historical aliases,
while reusing `extraTools.ts` and `toolContext.ts` for the metadata responsibilities
introduced on `main`. Contract tests compare actual native validation separately
from description enrichment and explicitly retain required source authorization.
No source authorization is inferred from an MCP read-only hint.

## Four Seasons and remaining performance limits

The unchanged fixture contains 4,079 layers, 42,512 keys, 7,863 tracks, two
timelines and a 48-second main animation. Under the same **512 MiB participating
managed-resource policy**, ten full plays completed in approximately 490.1 s:

| Measurement | Observed result |
| --- | ---: |
| Managed-resource peak | 46.25 MiB |
| Observed JavaScript heap range | 44.30–126.60 MiB |
| Registered canvases before / after | 21 / 21 |
| Synchronous viewport draw p50 / p95 | 183.6 / 251.0 ms |
| Animation evaluation p50 / p95 | 13.1 / 23.1 ms |

The historical v0.2.0 viewport p50/p95 was 30.7/47.5 ms in its environment.
That discrepancy remains documented; no general CPU speed improvement is claimed.
A contemporary control measured 180/293.3 ms, and a paired 120-frame output
comparison measured p50 102.2→103.5 ms with 12 exact RGBA checkpoints. Those
controls did not establish a large output-contract-specific regression or explain
all environmental variance. They do not erase the historical difference.

Managed bytes, JS heap and native process memory overlap and must not be added.
The 512 MiB policy is not an all-browser/decoder/GPU-driver/OS RAM cap.

## Output and feature limits

Final raster output uses full source layers rather than viewport LOD proxies.
The existing raster path still renders at composition resolution before scaling;
true resolution-independent output, FP16/color work and full Export E0 are later
work. Basic SVG/native runtimes do not support every expression/effect; inspect
warnings and use explicit bake/convert where required. This release does not
introduce boxed 3D, a full 3D workspace, Poly/UV/Blob or new simulation/CFX solvers.
The diagnostics receiver is implemented; public deployment is not implied.

## Reproduction and publication

```sh
npm ci
npm run cli:build
npm test -- --maxWorkers=2
npm run cli:test
npx tsc --noEmit
npm run mcp:build
npm run build
npm run cli:pack
```

Stop the target checkout's Next server before dependency installation or builds.
Browser harnesses require the fixtures described in their protocols; private
project files and raw QA artifacts are deliberately excluded.

The release PR must pass **Tests and builds** before merge. The published GitHub
release records the final main SHA, tag, CI and CLI archive checksums. Root and
CLI source versions are 0.3.0. The private editor root is not published to npm;
the attached CLI archive is a GitHub asset, not a registry publication.
