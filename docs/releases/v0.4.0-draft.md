# Draft: Chorono v0.4.0 — Spline modeling

**Unpublished candidate.** The modeling code is currently in the local `main` working tree, not in a commit on GitHub `main`. Do not publish or tag this release against `a4d4e64`.

## Proposed GitHub release body

Chorono adds four spline modeling operations through a dedicated dock panel and the scripting API.

### Modeling tools

- **Offset:** Generate an editable parallel contour from an open or closed spline. Choose outward/inward for closed contours or left/right for open contours.
- **Outline:** Generate an editable, equal-distance band around a contour. Closed bands use even-odd fill; open bands have caps.
- **Chamfer:** Cut selected spline corners and join the trimmed edges with straight segments.
- **Fillet:** Round selected corners with a radius and tangent cubic joins. The requested radius is exact for two straight edges.
- Preview the result before Apply, or Cancel it. Apply is a single Undo step. Offset/Outline preserve the source and add a sibling layer; Chamfer/Fillet replace only the selected contour and reject conflicting animation tracks.

### Scripting

Use `layer.spline.offsetContour`, `outlineContour`, `chamferCorners` and `filletCorners` from the script console or MCP `run_script`. Offset/Outline return the new layer ID. See [the modeling API guide](../en/spline-modeling.md).

### Known limits

Curved edges are flattened at a 0.25 layer-local pixel tolerance (up to the subdivision cap). Curved-edge fillets are G1 cubic approximations. Self-intersecting, collapsed, zero-length and overlapping results are rejected. The preview appears in the modeling panel.
