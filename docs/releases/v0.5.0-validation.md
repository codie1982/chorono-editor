## Open acceptance

The target remains the full smoke and B1–B6 regression on the release candidate.
The browser checks above cover a single recursive fixture and a still render.
Rigid cancellation in progress, manual boundary scrubbing, the PNG sequence,
live external Chorono Render handoff and the broader portable fixture matrix
remain open. Editor export checks cover the editor's in-tree player and runtime.
Compatibility of these new features in separately versioned Player, runtime
and SDK packages remains unverified. [Manual test plan](../tr/releases/v0.5.0-manual-test-plan.md)
