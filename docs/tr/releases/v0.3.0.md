# Chorono v0.3.0 — Düzenlenebilir animasyon ve güvenli ajan işbirliği

12 Kasım 2026. [English](../../releases/v0.3.0.md) ·
[Doğrulama ve sınırlar](../../releases/v0.3.0-validation.md)

3D öncesi tamamlanan çalışmalar `main` altında birleşir. Ajanın oluşturduğu
sahneyi elle düzenleme, sonraki ajan işleminde bu düzenlemeyi koruma ve sayfayı
yeniledikten sonra aynı oturumdan devam etme akışı geliştirilmiştir.

| Alan | Bu sürümde yapılanlar |
| --- | --- |
| Viewport | Pivot/anchor, seçim ve ilk sürükleme; mouse release, guide taşıma ve sürekli şekil çizimi düzeltmeleri |
| Animasyon yolu | Viewport'ta hareket yolu/key noktası düzenleme ve Timeline senkronizasyonu |
| Çoğaltma | Alt basılıyken mouse release ile tamamlanan drag-copy; alt ağaç, referans ve animasyon koruması |
| Array | Çoklu seçimde linear/radial/path düzenleri; önizleme, Apply/Cancel, tek Undo |
| Yerleşim | Komşu yatay/dikey mesafe düzenleme, kalıcı ruler guide, kilitleme/gizleme, sahne dışı düzenleme |
| Pan ve araçlar | M/H ile önceki araca dönüş; kontrol düğmelerinin pointer olayları, cursor guide sınırları, bağlamsal spline araçları |
| Hiyerarşi | Scene Explorer/Timeline ortak ağaç, alt ağaç işlemleri, açık Find in Timeline ve geçici isolation |
| Timeline | Set Key ve uzun basma/menü ile kanal seçimi; toplu key düzenleme, temizleme ve kare/key/baş/son gezinmesi |
| Procedural | Sayısal eğrilerde preview ve hata/örnekleme sınırlarıyla native key bake |
| Expression | Sayısal formüller; desteklenen number/boolean/string/color/Vec2 özelliklerde canlı expression; ortak zaman/parametre değerlendirmesi |
| Input hesabı | Calculate once, authored değere dönüştürme, fallback koruma ve desteklenen expression bake |
| Oturum | Otomatik kayıt, session ID, son oturum ve sınırlı Undo/Redo geçmişini geri yükleme |
| MCP | Her kaynak değişikliğinde güncel get_scene/revision ve tek kullanımlık readToken; atomik batch ve plan tokenı |
| Köken | İnsan/ajan creation ve son alan yazarı; kopyalanan içerik kaydı, Undo/Redo ve portable kayıt uyumu |
| Araç kataloğu | Tipli şemalar, açıklamalar ve odaklı discovery; eski isimleri bozmayan tercih edilen alias'lar |
| Tanılama | Kalıcı onay, sınırlı anonim özet kuyruğu, receiver API/depo, versiyon kontrolü; tekrar sayılı Yeni/İnceleniyor/Düzeltildi paneli |
| Yardım | Ortak Help kontrolüyle 58 rehber hedefi, gerçek component dokümantasyon hostu ve yeni başlangıç demosu |

Undo/Redo geçmişi toplam 50 adım ve yaklaşık 64 MiB kaynak tahminiyle sınırlıdır.
Yerel tarayıcı kurtarması harici portable proje kaydının yerine geçmez. Onay
olmadan tanılama verisi gönderilmez; herkese açık alıcı servis kurulumu ayrı iştir.

Final raster çıktı viewport LOD proxy'sini değil kaynak katmanları çizer.
Export E0, gerçek çözünürlükten bağımsız final renderer ve bütün formatlarda tam
özellik eşliği bu sürümde tamamlanmış sayılmaz. Canlı expression desteği
renderer/runtime'a göre değişir; uyarıları inceleyin veya açıkça bake/convert yapın.

Four Seasons 10 oynatma kabulünde aynı 512 MiB managed politikası altında
46,25 MiB tepe gözlendi. Tarihsel v0.2.0 CPU süreleriyle fark sürmektedir;
genel hız artışı veya bütün tarayıcı/işletim sistemi belleğine kesin sınır iddiası
yoktur. Yeni birleştirme testleri ve önceki tarayıcı kabul kapsamı
[doğrulama raporunda](../../releases/v0.3.0-validation.md) ayrıdır.

3D, Poly/UV/Blob, yeni cloth/fluid/fracture çözücüleri, CFX/tracking ve tam
Export E0 sonraki plandadır. 2D editör mevcut çalışma alanıdır.

Kurulum için [İngilizce sürüm notlarındaki](../../releases/v0.3.0.md#install-this-version)
tag'e sabitlenmiş adımları kullanın. GitHub release CLI 0.3.0 tarball'ı,
doğrulama kaydı ve SHA-256 dosyası içerir. npm registry yayını yapılmaz.
